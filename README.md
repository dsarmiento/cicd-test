# dsarm-test

A minimal test Python project.

## Installation

This project is not yet published to PyPI, but you can install it locally:

```bash
pip install .
```

## Usage

Print "Hello, World!" with the package version:

```bash
dsarm-test
```

Example output:
```
Hello, World! Version: 0.1.0
```

## Project Structure

- `dsarm_test/__init__.py` — Package versioning logic.
- `dsarm_test/cli.py` — Console script entrypoint.

## Development

To run the CLI script directly:

```bash
python -m dsarm_test.cli
```
